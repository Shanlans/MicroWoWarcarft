# Micro WoW - 像素版魔兽世界

一个完全用 HTML5 Canvas + 原生 JavaScript 构建、零依赖、零下载、**双击即可运行**的像素风单机 RPG。
灵感来自经典魔兽世界:艾尔文森林 → 西部荒野,3 个职业、9 种怪物、完整任务线,最终 Boss 战击败范克里夫。

## 开始游戏

方法一(最简单):
- 直接双击 `index.html`,在浏览器中打开即可。

方法二(建议):
- 在项目根目录运行:
  ```bash
  python3 -m http.server 8000
  ```
- 浏览器访问 `http://localhost:8000`

> 所有精灵、怪物、地图均由 JS 运行时程序化像素绘制,**不依赖任何图片或音频文件**。

## 操作

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` 或方向键 | 移动 |
| 鼠标左键 | 选择目标 / 点击 NPC 对话(需靠近) |
| `Tab` | 选择最近的敌人 |
| `1` ~ `5` | 释放技能 |
| `B` | 背包 |
| `C` | 角色面板 |
| `L` | 任务日志 |
| `Esc` | 保存并返回菜单 / 关闭面板 |
| `空格键` | 死亡后复活 / 通关后继续 |

## 玩法

- 在主菜单选择 **新游戏**,从三种职业中选一种:
  - **战士**:高血量近战爆发(主属性 力量)
  - **法师**:远程魔法输出(主属性 智力)
  - **猎人**:稳定远程输出(主属性 敏捷)
- 出生在闪金镇,点击带 `!` 头顶的 NPC 接任务
- 击杀野外怪物、完成任务、升级、学习技能、购买装备
- 5 级后可从闪金镇东边走到 **西部荒野**,挑战更强的敌人和 Boss

## 区域与怪物

### 艾尔文森林(1-5 级)
- 野猪、林地蜘蛛、狗头人矿工、迪菲亚强盗、强盗头目

### 西部荒野(5-10 级)
- 豺狼人、迪菲亚法师(远程)、迪菲亚监工、收割机器、**Boss 范克里夫**

## 任务线
- **镇长 索尔玛**:野猪肉风波 / 狗头人的阴谋 / 被偷的信件
- **元帅 达格兰**:强盗头目
- **长官 格里安**(西部荒野):收割机威胁 / 范克里夫的末日

## 文件结构

```
MicroWoWarcarft/
├── index.html           # 入口
├── css/style.css
└── js/
    ├── input.js         # 键鼠输入
    ├── assets.js        # 程序化像素资源
    ├── camera.js        # 摄像机
    ├── items.js         # 物品/装备表
    ├── skills.js        # 技能表
    ├── combat.js        # 战斗公式与伤害飘字
    ├── entity.js        # Entity 基类
    ├── player.js        # 玩家
    ├── enemy.js         # 敌人 AI
    ├── world.js         # 地图与世界
    ├── inventory.js     # 背包/角色面板
    ├── npc.js           # NPC 定义
    ├── quests.js        # 任务系统
    ├── dialog.js        # 对话/商店/训练师
    ├── ui.js            # HUD
    ├── save.js          # localStorage 存档
    └── main.js          # 主循环与状态机
```

## 自动存档

- 按 `Esc` 时会自动保存
- 存档使用 `localStorage`,存储在浏览器本地
- 主菜单的 **继续游戏** / **删除存档** 可管理存档
